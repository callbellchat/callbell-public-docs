### Tag Object

| Field   | Type   | Description                                                                                     |
| :------ | :----- | :---------------------------------------------------------------------------------------------- |
| `label` | string | Name of the tag. Contacts reference tags by this label.                                         |
| `color` | string | Color of the tag in the Callbell dashboard (e.g. `green`). It can be `null` for older tags.    |
